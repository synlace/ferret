- feat(runs): New Runs system for automated script plan execution (no LLM); dedicated `/runs` page with live SSE terminal output, copy-to-clipboard, and download-as-log
- feat(runs): Re-run button on completed/errored runs — creates a new run record in the same workspace (files overwritten, log preserved per run)
- feat(plans): Split plans into Scripts (`plans/scripts/*.yaml` + `.sh`) and Prompts (`plans/prompts/*.md`); Plans page now has Scripts / Prompts filter tabs with distinct colour badges
- feat(plans): `subdomain_enum` rewritten as a real bash script — subfinder passive enum, ffuf DNS brute-force, liveness probe, optional nuclei scan, human-readable `notes/subdomains.md` report, and `notes/ferret_manifest.json` fan-out
- feat(manifest): `ferret_manifest.json` fan-out — scripts write per-host workspace specs on clean exit; platform creates child workspaces, writes files, and schedules follow-on runs automatically without knowing the methodology
