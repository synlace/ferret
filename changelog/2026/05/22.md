# [2026-05-22]
### Added
- feat(hunts): add workspace file-type subdirs, write_note/write_credential AI tools, and auto-promotion

  Each hunt session now creates 7 subdirectories: `workspace/` (AI scratch area),
  `scripts/` (proven scripts), `tests/` (passing tests), `notes/` (markdown notes),
  `credentials/` (captured creds), `source/` (target source), `docs/` (target docs).

  Two new AI tools in the Notes group: `write_note` (writes `.md` to `notes/`,
  naming: `<topic>.md`) and `write_credential` (writes to `credentials/`,
  naming: `<service>_<type>.txt`).

  Auto-promotion: `run_script` exit 0 moves the file from `workspace/` to `scripts/`;
  `write_test` all-passed pytest moves the file from `workspace/` to `tests/`.

  `run_script` now accepts an optional `name` parameter (`<action>_<target>` slug)
  for descriptive filenames. System prompt updated with workspace naming rules and
  guidance for `write_note`/`write_credential`.

  Backend: `routers/hunts.py`, `chats_execute.py`, `chats_runners.py`, `chats_tools.py`,
  `chats_ai.py`, `chats_crud.py`. Frontend: `FileTree.tsx`, `NewFileModal.tsx`,
  `HuntsList.tsx`, `page.tsx`.

- feat(plans): move built-in plan prompts to .md files with YAML front-matter

  The four built-in hunt plans (Quick Recon, Full Recon, API Surface, Subdomain Enum)
  are now stored as `src/apps/api/plans/*.md` files. The seeder upserts them at startup
  so prompt edits take effect on restart without code changes. Prompts updated to
  reference `write_note`, `write_credential`, and script naming conventions.

- feat(lab): add nuclei vulnerability scanner to ferret-lab sandbox

  Installed via `go install github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest`
  in the lab Dockerfile alongside katana and subfinder.

- feat(hunts): add `run_nuclei` AI tool for template-based vulnerability scanning

  New tool in the Execution group. Runs nuclei inside the ferret-lab sandbox
  against a target URL or host using community templates. Supports template
  tag/path filtering, severity filtering, proxy routing, and extra flags.
  Wired into all three dispatch paths: `chats_litellm.py`, `chats_crud.py`,
  and `chats_execute.py`. Results truncated to 16 KB.

### Changed
- feat(hunts): group AI tools by type in the Context pane

  The AI Tools section of the hunt Context panel now organises tools into
  five collapsible groups — Proxy History, Findings, Testing, Execution,
  and Sources — instead of a flat unsorted list. Each group header can be
  clicked to collapse or expand it; state is persisted to `localStorage`
  across page reloads.

  Backend: added `group` field to every tool definition in `chats_tools.py`;
  the `/api/tools` endpoint now includes `group` in its response.

- fix(hunts): persist thinking block collapse state across page reloads

  `ThinkingBlock` now accepts a `persistKey` prop and reads/writes its
  collapsed state to `localStorage` (prefix `ferret_thinking_collapsed:`).
  Keys are `sessionId:msgIndex:thinking`, matching the pattern used by
  tool call groups.
