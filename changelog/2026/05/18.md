# [2026-05-18]

### Added
- feat(sources): add project-scoped Sources feature — reference files (API docs, source code, OpenAPI specs, notes) stored on the filesystem under `data/sources/{project_id}/`; files can be uploaded via the API or dropped directly on the host
- feat(sources): new REST API `GET|POST|PUT|PATCH|DELETE /api/projects/{project_id}/sources[/{filename}]` with multipart upload support; content stored as UTF-8 text files, max 512 KB per file (configurable via `MAX_SOURCE_SIZE_KB`)
- feat(sources): two new AI agent tools — `list_sources` (discover available reference files) and `read_source` (load full content into context); system prompt updated to instruct the agent to consult sources before analysing proxy traffic
- feat(sources): Sources panel in Projects UI — `BookOpen` button per project row opens `SourcesSheet` with file list, upload, and delete

### Added
- feat(tools): `search_requests` AI tool now accepts `method`, `status_code`, and `host` filter parameters, wired through to the DB layer — the LLM can now filter proxy history the same way the UI does
- feat(tools): `GET /api/tools` endpoint returns the full tool catalog with human-readable `label` fields
- feat(tools): per-session `enabled_tools` column in `chat_sessions`; `PATCH /api/chats/{id}` accepts the new field to persist which tools are active
- feat(tools): AI Tools sidebar in Hunts fetches the catalog dynamically from the API and renders checkboxes; state is persisted per session via `PATCH`
- feat(tools): "Enable all" / "Disable all" bulk actions in the AI Tools sidebar

### Changed
- feat(tools): system prompt is now built dynamically — disabled tools are omitted from the workflow order and pytest rules sections; when all tools are disabled an explicit notice is injected so the LLM does not describe tools it cannot use
- feat(tools): `resolve_tools` helper centralises tool filtering; used by all three agentic loops (non-stream, stream, background hunt)
- fix(ui): change UI branding from "FERRET" to "Ferret" across login page, app shell, setup wizard, page title, and test spec
- fix(ui): replace orange accent colour with brand gold (#EDC47E) via a new `brand` Tailwind colour scale; all `orange-*` classes replaced with `brand-*` across all UI components; button text changed to `text-neutral-900` for legibility on the lighter gold background

### Fixed
- fix(tools): disabled tools are now blocked at execution time with `exit_code: 1` if the LLM attempts to call them (hallucination / history-replay guard)
- fix(tools): `_run_plan_in_background` was ignoring `enabled_tools` and sending the full tool list to the LLM
- fix(tools): `resolve_tools` now correctly returns an empty list when `enabled_tools` is `[]` (previously treated as `None` = all enabled)
- fix(ui): `/api/tools` fetch was hitting the Next.js port (3000) instead of the FastAPI port (8000)
